Foundation

Combining Skills & Subagents
Master Claude Code · Skills
Foundation
Build specialist agents (researcher, writer, outreach) each equipped with custom skills, run in parallel across your prospect list.
  • Skills hold specialized logic: ICP rules, messaging guidelines, research criteria
  • Link skills to sub-agents via frontmatter: skills: [prospect-researcher]
  • Sub-agents do NOT inherit skills from parent — must be explicitly declared
  • Sub-agents autonomously fix side issues (errors, gaps) during execution

Context Window Management
My Daily Workflows · Feb 2026
Foundation
Long-running agent systems degrade without context discipline. Keep your orchestrator lean by offloading heavy tasks to sub-agents.
  • AI is most capable in the first 30–40% of a fresh context window
  • Never load raw data into main session — use sub-agents to summarize first
  • Use a "Plan File" to carry context across sessions without re-explaining
  • Monitor context % in the status bar; restart if it jumps unexpectedly

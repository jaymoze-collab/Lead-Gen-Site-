06
Get Airtable Access Token + Connect MCP
Connect

Prerequisite — Verify Node.js is installed:

bash
node --version && npx --version

If either command returns "not found", install Node.js first: go to nodejs.org → download the LTS version → run the installer → open a new terminal and verify again before continuing.

Part A — Get your Airtable Personal Access Token:

Go to airtable.com/create/tokens → click "Create new token".

Configure it with these settings:

Name: Lead Gen Agent MCP
Scopes: data.records:read, data.records:write, schema.bases:read
Access: Lead Gen Agent (your base only)

Click "Create token" → copy the token immediately (it won't be shown again). Save it in a secure note or password manager.

Part B — Connect Airtable MCP to Claude Code:

In your terminal (from your project directory), run:

bash
claude mcp add airtable -e AIRTABLE_API_KEY=YOUR_TOKEN_HERE -e PATH="/Users/YOUR_USERNAME/.nvm/versions/node/v24.15.0/bin:/usr/bin:/bin" -- /Users/YOUR_USERNAME/.nvm/versions/node/v24.15.0/bin/npx -y airtable-mcp-server

Replace YOUR_TOKEN_HERE with your actual token and YOUR_USERNAME with your Mac username (e.g. josephmosley). The full npx path and explicit PATH are required because Claude Code launches MCP servers in a restricted environment that doesn't inherit your shell's PATH.

Note: The correct package is airtable-mcp-server (not @airtable/mcp-server) and the env var is AIRTABLE_API_KEY (not AIRTABLE_PERSONAL_ACCESS_TOKEN).

To verify: run claude, then type /mcp — you should see airtable in the list as connected.

MCP (Model Context Protocol) is how Claude Code connects to external tools. Once the Airtable MCP is connected, you can tell Claude "create a new record in the Contacts table" and it will do it — no manual data entry, no copy-pasting.

The token scopes are intentionally minimal: read records, write records, read schema. Claude doesn't need permission to delete bases or modify billing — never give more access than needed.

⚠️ Phase 0 Troubleshooting
▼
"command not found" after installing Claude Code
Your terminal's PATH may not include npm global packages. Run export PATH="$PATH:$(npm prefix -g)/bin" and try again. For a permanent fix, add that line to your ~/.zshrc.
Airtable MCP shows "Failed to connect" — npx not found error
Node.js is not installed. Download and install the LTS version from nodejs.org. After installing, open a new terminal and verify with node --version && npx --version. Then re-run the claude mcp add airtable command using the full npx path as shown in Step 8.
Airtable MCP shows "Failed to connect" — env: node: No such file or directory
Claude Code's MCP environment doesn't inherit your shell's PATH. Use the full path to npx and set PATH explicitly in the command: claude mcp add airtable -e AIRTABLE_API_KEY=YOUR_TOKEN -e PATH="/Users/YOUR_USERNAME/.nvm/versions/node/v24.15.0/bin:/usr/bin:/bin" -- /Users/YOUR_USERNAME/.nvm/versions/node/v24.15.0/bin/npx -y airtable-mcp-server
Airtable MCP shows "Failed to connect" — 404 Not Found @airtable/mcp-server
The package @airtable/mcp-server does not exist on npm. The correct package name is airtable-mcp-server (no scope prefix). Remove the broken entry with claude mcp remove airtable and re-add using the correct package name.
Terminal shows zsh: command not found: -e after running the mcp add command
The command was split across multiple lines using backslashes — zsh interpreted each line as a separate command. Run the entire claude mcp add command on a single line with no line breaks.
Airtable MCP shows as connected but returns errors on test 3
Check that your token has the correct scopes (data.records:read, schema.bases:read). Re-generate the token at airtable.com/create/tokens and re-run the claude mcp add airtable command with the new token.
Gmail authentication keeps redirecting or failing
Make sure you're signing in to the correct Google account. Try in an incognito window. If still failing, check that your Google account doesn't have 2FA restrictions blocking OAuth apps.
/mcp shows no servers listed
Exit Claude Code (/exit), navigate to your project directory (cd ~/lead-gen-agent), and restart (claude). MCP servers are registered per-project — they only appear when Claude is started from the correct directory.
API billing error when running prompts
Go to console.anthropic.com → Billing → confirm your payment method is valid and credits are available. Wait 5 minutes after adding credits before retrying.

03
Review & Refine the Output
Build

Review each of the 5 sections using these criteria:

ICP: Does this match who you've actually closed deals with (or who you most want to target)?

TAM: Does the number feel realistic, not inflated? Are the data sources reasonable?

Positioning: Would your best prospect nod their head reading this?

Pain Points: Is this the language they use, not the language you use in your sales deck?

Messaging: Do the subject lines feel human? Would you open them? Do the LinkedIn notes sound natural, not robotic?

For each section that needs work, tell Claude exactly what to change:

example revision prompts
# If subject lines sound too salesy:
"Rewrite the subject lines to sound more like a colleague reaching out,
not a vendor pitching. No buzzwords. No 'quick question'."

# If pain points are too generic:
"The pain points are too vague. Rewrite them with specific scenarios —
describe a moment in the prospect's week when they feel this pain."

# If ICP company size is off:
"Adjust the ICP: focus on companies with 15-75 employees, not 10-100.
The sweet spot is post-product-market-fit but pre-scaling-the-team."

Iterate until all 5 sections feel accurate and usable. Don't rush this — it's the foundation everything else is built on.

Every downstream agent reads from this context. A vague ICP means vague prospect research. Generic messaging means generic outreach. The 20 minutes you spend refining this will multiply across hundreds of outreach touchpoints.

The most common mistake: approving pain points that sound like features ("they need better automation") instead of problems ("they have two SDRs who spend 70% of their time on manual prospecting and still can't hit quota").
